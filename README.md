# 🛒 Shopping List Manager

A simple shopping list manager built with **Python** that runs in the terminal. This project was developed to practice programming fundamentals, data persistence, and code organization.

## ✨ Features

- **Insert items:** Add new products to your shopping list.
- **Delete items:** Remove products by selecting their number.
- **List items:** Display all products currently in your list.
- **Data persistence:** Save and load shopping list data using JSON.
- **Input validation:** Handle invalid options and user input.
- **Error handling:** Manage common errors when reading and saving data.

## 🛠️ Technologies

- **Python** — Application logic and functionality.
- **JSON** — Data storage and persistence.
- **Git & GitHub** — Version control and project management.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later recommended.
- Git (optional, for cloning the repository).

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd shopping-list-manager
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## 💻 How to Use

Choose an option from the terminal menu:

| Option | Action |
|---|---|
| `I` | Insert a new item |
| `A` | Delete an item |
| `L` | List all items |
| `E` | Exit the program |

Your shopping list is stored locally in a JSON file, allowing items to remain available between executions.
